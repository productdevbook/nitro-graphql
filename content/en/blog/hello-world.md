## What is Nitro GraphQL?

Nitro GraphQL is a GraphQL integration module developed for **Nitro** and **Nuxt** applications. It automatically:

- Discovers GraphQL schemas and resolvers
- Generates TypeScript type files
- Supports both GraphQL Yoga and Apollo Server
- Works with Apollo Federation

## What's New in v2

### Nitro v3 and H3 v2 Support

Nitro GraphQL v2 has been rewritten to be fully compatible with Nitro v3 and H3 v2. This allows you to take advantage of the latest Nitro features.

### Vite Integration

The new version provides better integration with Vite. With Rolldown optimization, we achieved **up to 98% size reduction**.

### Debug Dashboard

A new debug dashboard is available at `/_nitro/graphql/debug` in development mode.
